# 📚 Die Magische Bibliothek

Eine gemütliche, scheinbar endlose 3D-Bibliothek (three.js), in der alle meine Apps, Blogeinträge,
Ideen und Archivstücke als Bücher in Regalen stehen – zum Selbst-Durchlaufen, Wiederentdecken und Staunen.

Vorne sitzt ein Zauberer-Bibliothekar, der im Notfall hilft (Suche + leuchtendes Irrlicht, das dir den Weg zeigt).
Laufen musst du aber selbst.

## Obere Etagen

Westlich der Trankküche steht der **Wendelturm**: Eine Wendeltreppe führt ins 1. Obergeschoss und weiter auf eine offene
Aussichtsplattform mit Glocke, Fernrohr und Wetterhahn (24 m hoch). Oben warten:

| Raum | Was dort ist |
| --- | --- |
| **Buchbinderei der Wichtel** | Wichtel hämmern, leimen und schleppen Bücher, ein Fließband (Hebel!), eine Buchpresse |
| **Dachgarten der Bienen** | Draußen über den Dächern: Bienen fliegen Blume → Stock, Königin Summ, ein leerer Blumentopf |
| **Eulenpost** | Eulen fliegen Briefe, Postmeisterin Federleicht am Schalter, Briefkasten zum Schreiben |
| **Traumkammer** | Bücher schlafen in Bettchen, Schäfchenwolken springen über einen Zaun, Mond-Mobile |

## Tasche & Item-Rätsel

Leuchtende Kleinigkeiten kann man einstecken (Tasche unten links, im Tagebuch unter „Tasche“). Manche Bewohner verschenken
etwas, andere wünschen sich etwas – daraus entstehen kleine Rätselketten mit Belohnungen (eine Katze, die dir folgt, eine
singende Riesenblume, eine reparierte Turmuhr, ein Dreifachsprung …). Taste `B` liest Briefe.

## Bewohner & Ostereier

Neun Bewohner wollen kennengelernt werden (Tagebuch → „Bekanntschaften“): der Bibliothekar, Frau Fingerhut (Uhrmacher-Maus),
Professor Puschel (Eule mit Monokel), Mirabelle (plaudernde Teekanne), Ritter Rostfrei (auf der Galerie), Gustav (Gärtnerigel),
Moos (Moosgolem), Lesefrida (Bücherraupe) und Pip, der Bücherwichtel in den Stapeln. Der Bibliothekar verrät auf „Wer wohnt hier?“,
wo man suchen kann.

Außerdem sind zwölf bemalte Eier versteckt, und es gibt Ostereier zum Selbstfinden – ein paar Hinweise ohne zu viel zu verraten:
alte Tastenkombinationen, Zaubersprüche beim Bibliothekar, ein Buch, das nicht ganz im Regal steht, eine Tür ganz am Ende
der Stapel, ungeduldiges Klingeln – und die Bibliothek kennt den Kalender (`?season=winter|autumn` zum Ausprobieren).

Überall verstreut: Bücher mit Beinen, Staubmäuse, Quietscheenten, Papierflieger, Bücher an Luftballons und Schilder mit Ratschlägen.

## Steuerung

`W A S D` laufen · `Shift` rennen · `Leertaste` springen (in der Luft nochmal = Doppelsprung) · `B` Brief lesen · Maus schauen · `E` / Klick interagieren · `Tab` Tagebuch · `M` Klang an/aus.
Auf dem Handy: linker Daumen = Joystick, rechts wischen = umsehen, tippen = interagieren, ⤒-Knopf = springen.

## Lokal starten

```bash
npm install
```

```bash
npm run dev
```

Nützliche URL-Parameter: `?spawn=garten` (direkt in einen Raum), `?debug` (FPS & Koordinaten), `?nolock` (Maus-Ziehen statt Pointer-Lock), `?lowfx` (ohne Bloom/Reflexionen für schwache Geräte), `?fixedres` (keine adaptive Auflösung).

## Eigene Projekte eintragen

Einfach `content/projects.json` bearbeiten – jedes Objekt ist ein Buch. Die Beispiel-Einträge (`"example": true`) kannst du löschen.

```json
{
  "id": "mein-projekt",
  "title": "Mein Projekt",
  "url": "https://…",
  "kind": "app",
  "room": "lesesaal",
  "shelf": "spiele",
  "status": "live",
  "year": 2026,
  "tags": ["spiel", "three.js"],
  "color": "#7a2e3a",
  "description": "Ein Satz oder drei."
}
```

Alles Weitere (neue Räume, Details, Geheimnisse) steht in **[EXTENDING.md](EXTENDING.md)**.

## Deploy

Bei jedem Push auf `main` baut eine GitHub Action die Seite und veröffentlicht sie auf GitHub Pages.
Einmalig nötig: im Repository unter **Settings → Pages → Source** „GitHub Actions“ auswählen.
